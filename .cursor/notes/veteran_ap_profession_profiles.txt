--------------------------------------------------------------------------------
1. HOW TO READ A PROFILE
--------------------------------------------------------------------------------

A spending profile partitions Extra AP (extraAp) into buckets by 1-based AP
ordinal within the veteran pool. Percents are of that slice. Omitted remainder
uses the mixed talent/spell loop (profession weights).

Cascade of unspent bucket leftovers (generator):
  attributes → special_abilities → talents → spells → mixed carry to next slice

Spell % only works for magical_status === full_caster (isFullCaster).
Consecrated Blessed Ones / shamans: spell_group_weight is NOT spent as spells;
any spell % is redirected to talents.

SA % only buys chain upgrades (sa_required already owned) plus wizard-requested
shield/armor/parry chains. It does NOT buy root maneuvers (Feint, Lunge,
Combat Reflexes) from discounted_SAs. Amazon/Warrior benefit; Gladiator mostly
overflows SA → talents.

Decision: ~18 named archetypes (shared 5 ordinal cuts), NOT 112 unique percent
tables. Distinction inside a bucket is already per-profession via biases.
Overrides (~15) only when the bucket mix itself differs.

Why five bands (not default 1–1000 / 1001–2500 / 2501+):
  - Column H attribute 12→13 ≈ 350 AP; 10% of 1000 = 100 AP never buys a raise.
  - Combat D-column cheap window ~ first 500 AP after package peak.
  - Generator treats extraAp ≥ 2000 specially (armor/shield first; residual VP/ASP).
  - Default 2501+ identical to mid band; heroic D-column TP14+ steps are poor value.

Shared ordinal cuts (ALL archetypes):
  Band 1 Competence     1–500     cheap talent/spell; NO attributes
  Band 2 First SA       501–1000  SA chains if root owned; NO attributes
  Band 3 First attrs    1001–2000 ~one H raise possible; aligns with 2000 threshold
  Band 4 Veteran        2001–3500 second attribute + SA + skills/spells
  Band 5 Heroic         3501–∞    lean attributes/SA; leftover cascades
